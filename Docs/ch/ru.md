## 4.0 (Последняя версия)
* **Ядро**:
  - Добавлена поддержка `systemd` (включены `FHANDLE`, `AUTOFS`, `AUDIT`, `CRYPTO_USER_API_HASH`, `CRYPTO_HMAC`),
  - Вырезаны неиспользуемые декомпрессоры initramfs (`LZ4`, `LZO`, `bzip2`, `LZMA`, `XZ`, `zstd`),
  - Отключен `CONFIG_DEBUG_INFO`.
  - Удалён суффикс `-st8` из версии,
  - Удалён параметр `logo.nologo` из cmdline,
  - Удалён параметр `buildvariant=userdebug` из cmdline,
  -  Удалён дублирующийся вызов `info->fbops->fb_imageblit(info, image);` в `bitblit.c`
  - Отладочные функции `dbg_fb_*` заменены на `cfb_fillrect` и `cfb_imageblit`
* **rootfs**: 
  - Исправлен race condition при старте WiFi (`mtk-wifi` и `wmt-pyloader` объединены),
  - Добавлена команда **`vibro`** в `twc`,
* **USB Gadget**: Серийный номер устройства теперь записывается в конфигурацию,
* **initramfs**:
  - Добавлен вывод статуса инициализации консоли ACM при загрузке,
  - Добавлено динамическое определение корневого раздела из параметров `cmdline` (выбирается последний переданный параметр `root=`, при этом игнорируются параметры вида `root=/dev/ram*` с выводом предупреждения) вместо захардкоженного `/dev/mmcblk0p41`,
  - Увеличено время ожидания корневого устройства (`root_timeout`) с 15 до 25 секунд.
* **install.sh**: 
  - Переработан интерфейс взаимодействия с пользователем (улучшение UX),
  - Добавлен флаг `--skip-device-verification`,
  - Теперь перед `oem cdms` выполняется `fastboot reboot bootloader`, без которого `oem cdms` не сработала бы.

## 3.0
* **install.sh**: 
  - Добавлен выбор образа LK (`lk_blossom_R.img` / `oem-cdms-logo-lk.img`),
  - Переработан интерфейс взаимодействия с пользователем (улучшение UX),
* **initramfs**:
  - Улучшена обработка ошибок,
  - Исправлен race condition при монтировании раздела с корневой фс,
  - BusyBox обновлен до версии 1.36.1 (статическая сборка aarch64),
* **USB Gadget**: Настроен USB `ConfigFS` с функцией последовательной консоли ACM в initramfs и rootfs для экстренной отладки и т. д. (115200),
* **Батарея**: Исправлено отображение статуса зарядки и процента уровня заряда батареи (переключено на аппаратный кулонометр со стороны ядра и исправлено масштабирование напряжения),
* **fbcon**: Исправлена видимость курсора (`cur 2`),
* **Динамическая сборка AIK**: Размер `boot.img` теперь зависит в зависимости от размера ядра и initramfs, что обеспечивает ускорение записи `boot` через `fastboot flash` до 4 раз,
* **Переименование утилиты**: (`tc` **→** `twc`) для предотвращения конфликта с системной утилитой Linux Traffic Control,
* **vbmeta**: Заменен оригинальный `vbmeta.img` от MIUI 12.5 на пустой `vbmeta.img`,
